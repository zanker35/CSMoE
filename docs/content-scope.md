## 资源与验证

游戏素材、应用和本地运行数据由外部资源包提供，不进入源码 Git 仓库。本地精简时另行清理了删除内容的模型、声音、动作、贴图、HUD、Lua 配置和专属地图素材；Git 提交本身不携带这些素材变更。

现有资源包需要提供保留内容的依赖。普通僵尸计分板共用的旧图片 `resource/hud/hud_scoreboard_bg_gundeath.tga` 在精简包中改名为 `resource/hud/hud_scoreboard_bg_zombie.tga`，使用旧包时应同步该名称。其它仍被保留模式或地图引用的共享资源必须保留。

构建和检查入口：

```sh
./tools/build-cso-ui.sh
python3 tools/check-cso-weapon-icons.py
python3 tools/check-cso-weapon-assets.py
./tools/run-cso-ui.sh --check
./tools/run-cso-ui.sh --smoke-quit
```

本地验证覆盖 44 项购买、18 人角色映射、五种模式分别启动、DM/TDM 死亡重生、生化Ⅰ/Ⅱ感染，以及真实模式下拉菜单的五个选项。检查不等于所有地图、武器攻击和联机胜利条件都已完整验收。资源检查仍会报告现有包的缺失项。
