## 每次迁入的记录模板

复制下面的条目，为实际迁入功能填写；不要把示例当作已经完成的记录。

```markdown
## YYYY-MM-DD：功能名称

- 来源：remote URL / branch / 完整 commit SHA。
- 目标：目标分支；实现提交可用提交主题或后续补充 SHA 定位。
- 行为范围：玩家在什么条件下得到什么新行为。
- 源码落位：旧路径 -> 新路径；无旧路径的新文件说明所属职责。
- 依赖：引擎 API、共享代码、服务端、预测、事件、HUD/菜单各有哪些改动。
- 资源：模型、外置动作、声音、精灵、文本/配置；来源与许可要求。
- 排除部分：来源功能中没有迁入的变体、平台或外围模块。
- 接口兼容：消息、函数表、结构体布局是否变化，怎样保持两端一致。
- 验证：实际执行的命令、对应结果、模式/地图/武器/人物及交互场景。
- 已知限制：遗留告警、缺失素材、尚未验证的行为。
```
